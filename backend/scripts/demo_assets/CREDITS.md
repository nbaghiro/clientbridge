`nl_logo.png` is a placeholder lighthouse mark drawn with a short script: a 512-pixel transparent PNG with a navy tower, an amber top and a blue beam, made for the white logo tile in the header.

Stock sources use the [Pexels License](https://www.pexels.com/license/), and the Unsplash photo uses the [Unsplash License](https://unsplash.com/license). Files are downloaded and stored locally, not hotlinked. Images are JPEGs with a maximum 1024-pixel edge; the complete 24-image Birchbark set is about 3 MB. Existing marketing catalog copies in `frontend/apps/site/public/images/demo/` share these sources.

The seed attaches an ordinary File row to every catalog item, including the travel shampoo parent and its 100 ml variant. Content-derived file IDs and storage paths prevent stale placeholder images after refresh. The travel bottle costs $8 CAD, with a $3.50 unit cost; historical invoices and payments are not repriced.

To refresh only the existing local demo catalog from the current assets, run from `backend/`:

```sh
.venv/bin/python -m scripts.demo_catalog
```

This requires the existing Birchbark catalog and the normal local development database/storage. It uploads the files before committing their metadata and updates only travel-shampoo catalog details and its opening stock unit cost. It preserves all other demo records and keeps previous image files available for existing references. Running it again does not create duplicate image rows.

The read-only browser regression covers loaded shop/booking photos and the travel price at desktop and narrow viewport sizes. Run `DEMO_E2E=1 pnpm exec playwright test e2e/demo-media.e2e.ts --workers=1` from `frontend/apps/connect/`. Local API requests explicitly use IPv4 to reach Clientbridge when another development process occupies IPv6 port 8701.
