# Job descriptions

Job descriptions for the first hires, written to be posted on LinkedIn. Each file starts with the same "About Clientbridge" paragraph, so any one of them can be posted on its own.

| Role | File |
| --- | --- |
| Founding Engineer | [founding-engineer.md](founding-engineer.md) |
| Founding Product Designer | [founding-product-designer.md](founding-product-designer.md) |
| Sales Lead | [sales-lead.md](sales-lead.md) |
| Marketing Lead | [marketing-lead.md](marketing-lead.md) |
| Customer Success Lead | [customer-success-lead.md](customer-success-lead.md) |

LinkedIn sets the location, workplace type, employment type and salary range in their own fields, so set those when posting. LinkedIn does not render Markdown headings: paste each section heading as its own line.

Keep the product details in these files in line with the site copy (`frontend/apps/site/locales/en-CA.json`) and the plan prices (`frontend/apps/site/src/content/plans.ts`) when either changes.
